# SHADOW VISUALS — облачная сборка Fabric

GitHub Actions автоматически собирает клиентский Fabric-мод для Minecraft 1.21.1, 1.21.4 и 1.21.11.

Открой Actions → Build SHADOW VISUALS Fabric mods. Сборка запускается автоматически при изменении FabricMod или вручную через Run workflow.

После успешной сборки файлы публикуются в Release с тегом fabric-mods-latest.

Мод заменяет только отрисовку панорамы главного меню. Он не регистрирует, не заменяет и не отключает звуковые события Minecraft.
